# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

E-mail **odinzeroofficial@gmail.com** with:

- a description of the problem and what an attacker could do with it;
- the steps to reproduce it, or a proof of concept;
- the OdinCMS version or commit you tested.

We will confirm we received it within 5 working days and keep you informed while we fix it. Once a fix
is released, we will credit you in the release notes, unless you prefer not to be named.

## Supported versions

Only the latest code on the `main` branch receives security fixes.
